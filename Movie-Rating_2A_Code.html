Introduction

What this assignment strives to achieve is to gather movie ratings obtained from a small number of people together and use SQL and R to analyze the gathered results. The movies chosen for this purpose include films like American Gangster, Moana 2, Annie, John Wick, Deadpool and Wolverine, Lilo and Stitch. Five people rated each of the chosen movies they have seen based on a grading system where 1 stood for the lowest and 5 for the highest ratings possible. If someone had not seen a particular movie, it was recorded as a missing value for that particular person.

The ratings obtained were kept in a relational database of PostgreSQL and then imported into R. The database consists of three tables storing the information on users, movies, and their respective ratings.

Database Design

In this assignment, PostgreSQL has been employed for the storage of data related to film ratings. In this respect, a relational database called movie_ratings was created, which consists of three different tables: users, movies, and ratings. The first table keeps the record of all the participants whereas the second one keeps the record of six chosen films. The last one makes the link between participants and movies and records ratings of the participants.

The tables are connected with the help of user_id and movie_id attributes. Ratings are defined within the range of 1 to 5. The absence of rating indicates that this person has not watched the film in question.

SQL CODE

The following SQL code was used to create the three tables in the PostgreSQL database. Primary and foreign keys were used to establish relationships between the tables, and a check constraint was used to restrict ratings to values from 1 to 5.

CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    person_name VARCHAR(50) NOT NULL
);

CREATE TABLE movies (
    movie_id INTEGER PRIMARY KEY,
    title VARCHAR(100) NOT NULL
);

CREATE TABLE ratings (
    user_id INTEGER,
    movie_id INTEGER,
    rating INTEGER,
    PRIMARY KEY (user_id, movie_id),
    FOREIGN KEY (user_id) REFERENCES users(user_id),
    FOREIGN KEY (movie_id) REFERENCES movies(movie_id),
    CHECK (rating BETWEEN 1 AND 5)
);

R Analysis

Once the ratings are saved in POstgreSQL, I utilized DBI and RPostgres packages for linking to the database. I executed an SQL query in R that combined the tables of users, movies, and ratings and brought back results in a dataframe called movie_data.

NOTE: The PostgreSQL database has to be created and filled with data using the mentioned SQL command before executing R analysis.

library(DBI)
library(RPostgres)

con <- dbConnect(
  RPostgres::Postgres(),
  dbname = "movie_ratings",
  host = "localhost",
  port = 5432,
  user = "raveenaboodram"
)

movie_data <- dbGetQuery(con, "
SELECT
    u.person_name,
    m.title,
    r.rating
FROM ratings r
JOIN users u ON r.user_id = u.user_id
JOIN movies m ON r.movie_id = m.movie_id
ORDER BY u.user_id, m.movie_id
")

Average Movie Rating

Next, I calculated the average rating for each movie. Since the dataset contains one missing value, I excluded missing values from the calculation. This allows each movie’s average to be calculated using only the ratings that were actually provided.

# Calculate the average rating for each movie
average_ratings <- aggregate(
  rating ~ title,
  data = movie_data,
  FUN = mean,
  na.rm = TRUE
)

# Display the average ratings

Results

The results show that American Gangster received the highest average rating of 4.75, followed by Lilo & Stitch with an average rating of 4.60. Moana 2 also received a relatively high average rating of 4.20. John Wick had an average rating of 3.80, while Annie received an average of 3.40. Deadpool & Wolverine had the lowest average rating at 3.20.

These results suggest that American Gangster was the most highly rated movie among the participants. However, its average was calculated from four ratings instead of five because one participant had not seen the movie.
